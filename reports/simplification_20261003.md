# 通用化与复杂度收缩检查

日期：2026-10-03。目标为减少特化规则和重复实现，保留多模态 RAG 主干；本轮不以提高小样分数为验收目标。

## 1. 按顺序执行的改动

### 等价清理

- 查询统一为 `query / fact_id / entities` 字典，删除字符串兼容分支。
- 删除关键词检索中未使用的论文限定 SQL 分支；限定论文补查继续直接重排该论文的全部候选。
- `retrieve` 统一返回全部重排后、按 `evidence_id` 去重的候选，删除 `all_candidates` 开关与另一处 Top-K 截断。最终名额继续由事实融合选择。
- 独立读图 schema 不再要求模型填写来源 ID；每次请求只对应一份原始图像证据，程序将其真实 ID 附到读数。

完成后，原有 142 项离线测试全部通过。测试夹具同步使用实际查询格式，继续检查融合、来源、完整证据及局部降级。

### 引用恢复与实体排名

- 删除长引文中 `is / are / of` 的连接词猜测修复。
- 删除数字表格专属的 50% 引文覆盖放宽；所有引文使用相同匹配规则。
- 保留 Unicode/空白/PDF 换行拆字归一化、逐字片段匹配、数字边界、唯一来源绑定和主证据选择。引文问题仍只影响辅助引用字段，不改写 `answer_value`。
- 删除精确实体的人工位置加分；实体仍参与精确关键词召回，重排顺序由 BGE 模型决定。
- 删除将 `100 / 000` 当作停用词的处理。数值检索继续受 trigram 最少三个字符的约束，未增加数值运算或答案内容检查。

### 未采用的上下文收缩

单独准备了删除稀有词页面排序与相关论文首页补充的版本。其他事实页锚点、原始证据与跨页邻居保持不变。

| 同题对照 | 原上下文 | 收缩上下文 |
| --- | ---: | ---: |
| 历史训练题数量 | 6 | 6 |
| 历史题答案值正确 | 4/6 | 4/6 |
| 这 6 题官方本地分数 | 0.722222 | 0.715556 |
| 新编固定证据题答案值正确 | 2/2 | 2/2 |

收缩版本中，q104 的倍率方向答对了；q482 从 `13.0` 变成 `13.02`，未通过官方数值容差，q576 遗漏一个标准引用。正确总数没有增加，因此没有把该上下文收缩合并到生产代码。

本实验将两个上下文补充同时删除，不能据此区分各自的贡献；单次模型输出也会波动。保留原实现是保守决定，小样结果不足以证明这些策略在全部问题中必需。

### 表格判定

之前两个长文字单元格就可能触发损坏表格回退。现在要求单行多列长内容中还出现数值列表，再标记为疑似粘连；合法长描述不再仅因字数触发额外模型转写。

该判断仍是启发式，无法可靠识别全部坏表，也可能误判合法的列表型单行表格。原表截图、异常局部回退和解析元数据保留，没有按论文名称、表号或答案值设置例外。

## 2. 验证方法与边界

- 所选模型为已配置的 DeepSeek，测试进程单独选择供应商，未修改 `.env`。
- 固定证据小样：q029、q104、q220、q518、q576、q482，以及两道人工新编表格题。历史题使用此前实际提供过的原始证据；新编题使用人工核对原页后的未改写页面文字。
- 题目、预期单位和原始证据发送给模型；标准答案、题型标签和配置文件内容仅留在本地。
- 8 份原始模型草稿由新旧引用函数分别重放，最终引用集合全部一致，核心答案值不变。删除这两处分支仍可能影响未来未覆盖的模型输出；引文匹配将更严格，程序不再自动修补这些措辞。
- 实体排名单因素：q029、q104 复用同一查询、向量候选和实际 BGE 重排结果。删除人工加分后，最终 Top-K 来源及顺序相同，扩展后送给模型的正文、页码和图片也相同；q029 的内部查询排名数字有所变化。无需为完全相同的生成输入重复调用模型。两题覆盖范围较小，不能证明全局无回退。
- PDF 技能用于原页视觉核对及表格结构检查；表格技能用于本地评分与结构化结果分析。复用已有 Docling 页面解析产物，不重新解析整篇 PDF。
- 两篇 PDF、四个实际页面的五张表格已检查：`amazon2023.pdf` 第 6、26 页，`gao2025.pdf` 第 31、32 页。检索文字和正常表格标记均保持一致；合法长文字单行表与坏表回退另外用离线合成文档覆盖。
- 官方评分只用于历史题，人工新编题单独报告数值与引用。历史训练题已经被多轮检查，不能称为独立留出集；新编两题也仅是固定证据生成验证，没有评估独立召回与整个未见领域。

本轮小样仍暴露未解决的质量问题：q220 的指标条件识别、q104 在部分固定上下文中的倍率方向、q518 的第二来源引文不匹配。它们在本轮引用收缩前的基线中已经出现，本轮没有新增针对这些题的解题分支，也未证明之前的提示词收缩完全无损。

## 3. 保留的功能

- 文本、表格、图像解析与检索，图表原图，脚注独立入库和高置信续表归组。
- 独立事实规划、同义查询去重投票、事实级融合及保底名额，一轮限定补查。
- 完整原文、单位和图片送模型推理；无程序算术复算或答案正确性判定。
- 原始来源绑定、结构化字段与比赛格式处理、局部异常降级。
- API 错误处理、并发、逐题保存和断点恢复。这些功能用于完成批量运行，继续保留。
- `ref_ids / supporting_materials` 仍作为没有有效 `supports` 结构时的兼容回退，未在缺少对照证据时删掉这两个模型字段。

本轮生产代码没有新增模块、依赖或配置开关。按包含空行的相同口径统计：`generate.py` 775 → 755 行，`retrieve.py` 266 → 248 行，`ingest.py` 594 → 597 行，合计净减少 35 行。更早的提示词收缩记录见 `quality_steps_20261003.md` 第 7 节，不计入此次减少量。
